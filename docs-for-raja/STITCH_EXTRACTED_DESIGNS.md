## 1. Visual Foundation (`Kintsugi Academic`)

| Token Category | Value | Application |
| :--- | :--- | :--- |
| **Canvas Background** | `#F7F3EA` | Soft washi paper tone; eliminates blue-light eye strain |
| **Surface (Cards / Inset)** | `#F1ECE1` | Level-1 container surface with crisp `1px` subtle outline |
| **Surface High / Hover** | `#EDE7E1` | Interactive card hover states and elevated sheets |
| **Primary (Authoritative)** | `#3D4E6B` (*Indigo Dye*) | Primary actions, navigation dock headers, active states |
| **Secondary (Accents)** | `#B65C3A` (*Terracotta*) | Critical circulars, urgent tasks, next milestone banners |
| **Success / Verified** | `#6B8A63` (*Sage Green*) | Attendance health, confirmed RSVPs, healthy cluster metrics |
| **Warning / Alerts** | `#D69A2D` (*Ochre Amber*) | Submission deadlines, exam alerts, time-sensitive notices |
| **Text Primary** | `#1D1B17` / `#23211D` | High-contrast WCAG AAA typography |
| **Text Muted** | `#666056` (*Sandstone*) | Subtitles, room labels, timestamps, metadata |
| **Typography Display** | **`Source Serif 4`** | Editorial literary titles, display headings, milestones |
| **Typography Body/UI** | **`Hanken Grotesk`** | Contemporary clean sans-serif for academic modules |
| **Elevation** | Tonal Layering + Soft Shadow | `0px 4px 12px rgba(35, 33, 29, 0.08)` |
| **Shape Language** | Restrained Geometry | `rounded-sm (2px)` buttons, `rounded-lg (8px)` cards |
